# Pixel Hero Fights: the game

A browser game built from the YouTube Shorts pipeline in `../fight`: the same heroes,
bosses, arenas, art and sounds, with the same fight rules (ported to TypeScript in
`src/sim/world.ts`). The design doc is in [DESIGN.md](DESIGN.md).

**Modes:** Duel (vs AI or 2 players on one keyboard, best of 3) and Boss Raid (you + 2 AI heroes
vs any of the 10 bosses).

**Controls:** P1 steers with WASD and fires the ult with Space. P2 uses the arrows and Enter.
Tab switches the mode in the menu.

## Run it

```bash
npm install
npm run export   # copies heroes, bosses, maps, art and sounds from ../fight (needs fight/.venv)
npm run dev      # http://localhost:5173
```

Stop the dev server before re-running `npm run export`: on Windows it holds the image files open.

## Content stays in the video pipeline

`public/content/*.json` and `public/assets/` are generated by `fight/tools/export_game.py`.
Change a hero in `fight/characters/<id>.json` (or a boss in `fight/fightsim/spec.py`) and re-export.
Don't edit the exported files by hand. The UI art is in `fight/art/ui/`, made by `fight/tools/gen_ui.py`.
