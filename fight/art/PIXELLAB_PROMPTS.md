# PixelLab art prompts

Generated by `python tools/art_prompts.py` from the `art` block in each `characters/<id>.json`. Edit those blocks, not this file.

## How to run it

1. **Step 1, anchors.** Generate the jobs marked *anchor* with **Create image (pixflux)** and the settings below. Regenerate (change the seed) until you love them: they set the look of the whole game.
2. **Step 2, everything else.** Use **Generate with style** (Pro) with the listed anchor as the style image, so every character matches. Without Pro, use pixflux with the same prompt and settings (the `fallback` in the JSON).
3. **Save** each PNG to the path shown (`characters/art/<id>/...`). The renderer will pick sprites up from there and fall back to the procedural drawing for anything missing.
4. Regenerate with **inpainting** for small fixes rather than rerolling a sprite you mostly like.

## Settings for every sprite

| Setting | Value |
|---|---|
| No background | on |
| Outline | `single color black outline` |
| Shading | `basic shading` |
| Detail | `medium detail` |
| View / direction | `side` + `south` (bodies, summons, icons); `side` + `east` (weapons, projectiles) |
| Guidance | 8 |
| Forced palette | `art/palette.png` (Arena-28, the same colours the interface uses) |

Sizes: character bodies 64×64, weapons 64×64 (trimmed automatically), summons, projectiles and icons 32×32, floor tiles 32×32. The new interface draws at 540×960 and scales ×2, so these map close to 1:1 onto the fighters.

**Rules that matter for this game**

- Bodies must stay **round**: the physics is a circle, so the art is a ball with a face, not a full figure.
- The HP number is no longer drawn on the ball, so faces can sit in the middle.
- Weapons point **right** with the handle on the **left edge**: the engine rotates them around the handle.

Shared style text (already inside every prompt): *16-bit pixel art game sprite, crisp chunky pixels, bold black outline, bright saturated colors, clean readable silhouette, centered on a transparent background, no text, no frame*
